# FinRisk Query 4.0 流程图绘图提示词（教师展示版）

## 可直接复制的提示词

~~~text
请绘制一张“FinRisk Query 4.0 合规风险分析流程图”，用于金融科技比赛向老师介绍系统的
整体工作流程。

画面采用 16:9 横向布局，白色或极浅灰背景，浅蓝色为主色，搭配少量橙色表示风险判断、
绿色表示案例检索。使用简洁的圆角矩形、细箭头和少量扁平图标，不要复杂特效、3D、霓虹
或大段文字。整体风格类似简洁的企业后台系统架构图，适合放入答辩PPT。

标题：
“多模态合规风险判断与相似案例检索流程”

按照从左到右、必要时上下换行的方式绘制以下主流程：

1. 用户输入
   小字：文本、PDF、图片、TXT、Markdown、DOCX

2. 统一输入与多模态抽取
   小字：原生文本 / PDF文本层 / RapidOCR
   补充：页码、坐标、OCR置信度、文件哈希

3. 六类场景分类
   小字：本地规则优先，高置信直接确定，低置信由LLM复核

4. 可逆切句与来源映射
   小字：sentence_id、全文偏移、页码、区域、前后文

5. 逐句两阶段本地风险初判
   小字：Stage 1 强组合规则 + Stage 2 场景加权关键词

6. 动态LLM语义复核
   小字：高置信句本地直出，中低置信句批量复核

7. 风险结果融合
   小字：逐句风险分、风险等级、风险标签集合

8. 检索判断
   使用一个简洁的菱形分支：
   - risk_score < 0.40：不检索案例，直接进入整体聚合
   - risk_score ≥ 0.40 且标签非空：进入相似案例检索

9. 标签对齐的混合案例检索
   小字：案例风险标签至少匹配一个
   第二行：BM25 + TF-IDF cosine → RRF融合 → 本地轻量重排

10. 文档整体风险聚合
    小字：整体风险分、风险等级、风险标签、Top相似案例去重

11. API 4.0 与浅色WebUI
    小字：原文高亮、逐句结果、相似案例、整体结论

其中“不检索案例”和“相似案例检索”两条分支最终都汇合到“文档整体风险聚合”。

在图底部增加一句简短说明：
“先判断文本风险，再按风险标签检索案例；案例相似度不参与风险定性。”

排版要求：
- 主流程清楚，节点不超过11个；
- 每个节点只保留标题和一行说明；
- 突出“本地规则优先、LLM按需复核、达到阈值才检索”；
- 不展示代码文件名、复杂算法公式、测试指标和大量字段；
- 中文文字清晰准确，箭头不要交叉；
- 画面简洁、浅色、专业，老师在PPT上一眼能够看懂。
~~~

## 简化结构参考

~~~text
用户文本/文件
    ↓
多模态内容抽取
    ↓
六类场景分类
    ↓
切句与来源映射
    ↓
两阶段本地风险初判
    ↓
动态LLM语义复核
    ↓
风险分、等级与标签融合
    ↓
是否达到案例检索阈值？
    ├─ 否 → 不检索 ─────────────┐
    └─ 是 → 标签过滤的混合检索 ─┤
                                 ↓
                     文档整体风险聚合
                                 ↓
                    API 4.0 / 浅色WebUI
~~~
