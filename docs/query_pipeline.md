# Query 分类、风险判断与相似案例匹配

## 六类场景

| 编码 | 使用场景 |
| --- | --- |
| `ST1_poster_sms_social` | 海报、短信、社交平台短文案 |
| `ST2_live_short_video` | 直播、短视频、口播话术 |
| `ST3_product_intro_detail` | 产品介绍、详情页 |
| `ST4_meeting_material` | 产品说明会、客户活动材料 |
| `ST5_training_telemarketing_callback` | 培训、电销、回访流程话术 |
| `ST6_penalty_backend_fact` | 处罚文书、后台业务事实 |

场景描述材料用途，不是风险标签。规则分类器输出全部候选分数、归一化置信度和证据；
达到最低分、领先差和置信度时本地直出，否则由统一 LLM 从六类中复核唯一类别。

## 抽取、切句与定位

文本、PDF、图片、TXT、Markdown 和 DOCX 使用同一个抽取契约。输出保留媒体类型、
SHA-256、页数、OCR页数、抽取方式、质量分、文本块/字词数和警告。PDF原生文本层优先，
扫描页与图片使用 RapidOCR。页码、OCR置信度、块/字词ID及归一化四边形均可回溯。

切句支持句末标点、空行、数字列表和社交平台项目符号。`RiskQuerySentence` 保持
`query_id / sentence_id / scene / text` 四字段；`source_mappings` 一一保存全文偏移、
页码、坐标和前后句上下文，Web用同一偏移生成原文风险高亮。

## 两阶段本地风险初判

1. 强规则阶段：组合正则、高精度后台违规模式和否定前缀处理；
2. 加权阶段：`关键词基础权重 × 资产来源质量 × 场景适配度`，多信号用 noisy-or 累积。

普通关键词不会“一词定风险”。`以合同为准 / 不构成承诺 / 收益存在不确定` 等限定语会
降低弱关键词信号；强组合规则保持高置信。初判输出阶段分、综合分、置信度、标签和证据。

## 动态 LLM 复核

- 高置信强规则句本地直出；中低置信句进入复核集合；
- 短 Query 把整篇句子放在同一批次提供上下文，只要求输出待复核句；
- 长 Query 按句数和字符预算分批，以有限并发降低总延迟；
- 提示词只含原文、场景、前后文和本地证据，绝不包含案例；
- 27标签允许多选，明确提示语义重复、上下位和包含关系可同时保留；
- 输出经 Pydantic 校验，未知标签丢弃，失败批次回退本地结果并写入警告。

风险等级仍使用 0.20 / 0.40 / 0.60 / 0.85 五档。案例相似度不进入风险分；本地强规则
与LLM复核分别按置信度融合。

## 检索门控与混合排序

默认只有 `risk_score >= 0.40` 且句子标签非空才检索。检索严格过滤案例标签，至少一个
标签与句子标签相交。排序流程：

```text
BM25 单元召回 ─┐
                ├→ 案例级 RRF → 词面覆盖/来源质量/短语命中轻量重排 → Top 3
TF-IDF 向量召回 ┘
```

两路召回复用同一中文 unigram/bigram 倒排表；向量通道为归一化 TF-IDF 余弦相似度，
无需外部权重。案例原文 fact/evidence 切片与启用的扩展表达继续来自现有统一案例库。

## 文档聚合与 API 4.0

整体分以最高句分为主，第二至第四个风险句只提供有限增益；无风险句不会因数量被抬高。
`risk_summary` 包含整体分/等级、阈值以上标签及对应句、Top去重案例、本地直出与LLM复核
数量、实际检索句数和警告。`risk_assessments[]` 包含每句最终分、本地分/置信度、标签、
理由、证据、定位信息和标签对齐案例。

接口错误：413 文件过大；422 抽取或字段错误；502 LLM供应商错误；503 场景分类需要LLM
但未配置。风险批次失败不终止整份材料，会明确降级并返回警告。
