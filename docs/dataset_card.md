# Query 数据集说明

生成日期：2026-08-28。所有数据均为中文；不包含真实个人敏感信息。数据构建命令：

```powershell
uv run python scripts/build_query_datasets.py
```

## 160 基准修订

ST4 共 30 条、ST5 共 25 条增加了 `【材料载体：…】` 前缀，使模型能看到现实输入中用户通常知道的载体上下文。前缀不包含风险结论；风险标签、证据、理由和样本数量未修改。其余 105 条 Query 原文未改。

## 开发集生成

- 使用已有 `query_text`、`expected_risk_type` 和 `relevant_cases`。
- 将“误导、隐藏重要信息、夸大宣传、夸大服务、错误解释保险责任”等历史写法映射到 27 类词表。
- 场景由确定性载体/文本规则派生，不能当作人工金标准。
- 与 160 基准执行规范化完全重复排除；当前无重复样本被保留。
- `relevant_cases` 只作为开发期弱监督，不作为人工检索测试集。

## 长尾增强

选择 160 基准中支持数不超过 10 且语义明确的 9 类：未按规定使用费率条款、虚列费用套取资金、电销违规、委托无资质机构销售、回访违规、避债避税、虚构收益率、欺骗投保人、贬低竞品。每类 4 条，共 36 条；不增强兜底标签“其他”。

## 已知限制

- 160 条规模仍小，长文本和少数标签置信区间较宽。
- 开发集场景和标签包含规则派生信息，不能用于对外宣称最终准确率。
- 长尾集是模板化合成数据，人工复核前不得加入训练。
- 检索质量最终指标等待队友提供独立人工相关性集合后再计算 Recall@K、MRR、nDCG@K。
