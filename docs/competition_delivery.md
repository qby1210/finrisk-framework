已实现：160 条人工复核测试基准、300 条开发集、36 条九类长尾增强集；标注规范、数据集说明；可重复构建脚本；full/local 两模式评测；二分类 Precision/Recall/F1、多标签 Micro/Macro-F1、完全匹配、Jaccard、逐标签指标、场景准确率、延迟/P95和阶段耗时。

## 性能策略

- 用户指定场景时跳过场景模型调用。
- 高置信规则直接输出；无 API 时规则回退，不阻断整条流程。
- DeepSeek 使用共享 HTTP 连接池、并发上限和短退避重试。
- 检索索引一次预热并复用；已测单条流程中主要耗时来自 LLM，检索只占很小部分。
- 报告分别保存 `evaluation_full.*` 和 `evaluation_local.*`，避免覆盖。
